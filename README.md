🏦 Bank Account System (Python OOP Project)
📘 Overview

This is a simple Bank Account System built using Object-Oriented Programming (OOP) concepts in Python.
It demonstrates real-world programming principles, including Abstraction, Inheritance, Encapsulation, and Polymorphism.

I created this project as part of my Python learning journey to understand how classes and inheritance work in real-life examples.

⚙️ Features
Create multiple types of accounts: Savings and Current
Deposit and Withdraw money
Supports overdraft limit for current accounts
Displays all account balances in the bank
Handles invalid inputs and errors gracefully

🧠 Concepts Used
OOP Concept	Example in Project
Abstraction	Account is an abstract base class defining a common structure
Inheritance	SavingsAccount and CurrentAccount inherit from Account
Encapsulation	Account balance is stored as a protected variable _balance
Polymorphism	Both account types override the withdraw() method differently
🖥️ How to Run

Run the Python file:
python bank_system.py

Follow on-screen instructions to see transactions and balances.
